API Data Analysis Project

1. Project Overview

This project demonstrates how to retrieve, extract, transform and analyse user data from the JSONPlaceholder REST API.

Python is used to retrieve JSON data, flatten nested records, create structured datasets and perform exploratory data analysis.

2. Objectives

Retrieve user records from a REST API.

Extract and inspect JSON data.

Transform nested JSON into Pandas DataFrames.

Create structured CSV datasets.

Examine data quality and identify missing values and duplicates.

Analyse user distribution by city and company.

Present findings using visualisations.

3. Data Source

API: JSONPlaceholder

Endpoint: https://jsonplaceholder.typicode.com/users

The API provides sample user records for testing and data analysis.

6. Installation

Clone the repository:

git clone https://github.com/Gigomkenya/api_data_analysis.git

Navigate into the project directory:

cd api_data_analysis

Install the required dependencies:

python -m pip install -r requirements.txt

7. Running the Project

Run the main Python script:

python main.py

This retrieves the API records and generates the following files:

users_data.json

users_core.csv

users_flattened.csv

Alternatively, open main.ipynb in Jupyter Notebook or VS Code and execute its cells.

Open analysis.ipynb to explore the datasets, perform data quality checks and generate visualisations.

8. Analysis Performed

The analysis notebook covers:

Dataset dimensions and previews.

Missing-value checks.

Duplicate-record checks.

Unique user ID checks.

User distribution by city.

User distribution by company.

Summary statistics and visualisations.

9. Expected Results

The JSONPlaceholder users endpoint provides 10 sample user records.

The project transforms these records into structured datasets suitable for further analysis and reporting.

10. Conclusion

This project demonstrates a complete introductory API data workflow, from data extraction and transformation to structured CSV exports and exploratory data analysis.

It provides a foundation for further work in data engineering, analytics and business intelligence.
